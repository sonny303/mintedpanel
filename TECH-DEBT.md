# Tech-Debt Register

The Stage 0 consolidated tech-debt register (E0.9 F0.9.5). Every TD item
recorded in the Devin sections of epics E0.0–E0.8, plus E0.9's own findings,
lives here as one row — debt recorded only inside epic prose is invisible at
build time; this register is read by every future session. Where epics carried
the same debt forward, the rows are deduplicated and cite all origin epics.

Triage cadence: the PM reviews this register **each design-review cycle and
before each stage promotion**. A row leaves the register only by being resolved
(name the resolving feature/PR in Disposition) or explicitly retired by the PM.
New debt is added in the same PR that incurs it. Design/visual deviations do
NOT go here — they go in `DESIGN-DEBT.md` (e.g. E0.9 TD-1, heading sizes).

Class vocabulary: `data-hygiene` · `infra` · `product-decision` · `process` ·
`ui` · `security`.
