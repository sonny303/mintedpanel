# Task-first admin UX coverage addendum — 2026-09-27

This addendum corrects the control-first audit in [PR #437](https://github.com/sonny303/mintedpanel/pull/437). It is a **new coverage pass**, not a claim that the 639 originally listed controls or 38 routes covered every expected admin task. The original pass started some tasks in the setup wizard and omitted actions absent from a page. Do not start another UX fix until an independent reviewer checks this task inventory against requirements, deployed source `2ea77b7a26083ed2cf90504f96d11601d88882d1`, open UX branches, and live staging.

## Execution rule

For every admin entity page, inventory both visible controls and expected tasks: create, find, view, edit, deactivate, and recover where applicable. Begin from the entity's sidebar entry, including when a redirect occurs. Exercise zero, one, and multiple records using disposable synthetic organizations and entities. Record the route, fixture, expected result, actual result, evidence, requirement or explicit product assumption, and user impact. Record a required action even when no button exists. Mark it `FAILED` when the requirement is contradicted, or `BLOCKED` when applicability or safe execution cannot be resolved; label source-only, user-reported, and staging-observed evidence separately. Test validation, cancel, save, refresh/reopen, empty, loading, error/retry, and disabled reasons for each applicable task. A row status is evidence for that row only; do not infer page completeness from it.
