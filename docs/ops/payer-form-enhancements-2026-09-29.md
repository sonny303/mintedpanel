# Payer form enhancements — September 29, 2026

Scope: the seven reported ZIP, date, phone, taxonomy, Medicare PTAN, and BCBSKS fill problems. Planning and independent review used Astra/high; implementation used Luna/xhigh. Existing unrelated working-tree changes were preserved.

| Request                              | Change and evidence                                                                                                                                                                                                                                                                                        |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Five-digit ZIP                       | Reusable `zip5` shaping converts valid ZIP+4 values while preserving leading zeroes.                                                                                                                                                                                                                       |
| Six date formats / blank date fields | Mapping choices now include MM-DD-YYYY, MM/DD/YYYY, DD/MM/YYYY, DD-MM-YYYY, YYYY/MM/DD, and YYYY-MM-DD. Native date inputs receive canonical ISO dates independently of the display format. DOB and license issue/expiration values were already projected.                                                |
| Phone formatting                     | Mapping choices support ten digits, XXX-XXX-XXXX, (1) XXX-XXX-XXXX, and +1XXXXXXXXXX. Unsupported international numbers and extensions are preserved instead of silently truncated.                                                                                                                        |
| Incorrect date year                  | PrimeFaces date fields receive their required keydown-before-input sequence. Bounded readback detects dates changed by the payer's script, including repeated fills, and reports the affected field without recording the entered value. The exact reported 6100 year was not reproduced on the live form. |
| BCBSKS taxonomy                      | The extension recognizes a visible PrimeFaces dropdown's native backing select, excludes its internal focus input from capture, and selects through the real widget. Runtime matching uses the complete live option set.                                                                                   |
| Medicare PTAN picker                 | `group.payerIssuedId` is searchable as payer-issued group ID / Medicare PTAN. It reads the active payer-network target for the selected case's organization, group, payer, and state, with the same case's legacy group ID as fallback. No case means unresolved. No new PTAN storage is introduced.       |
| Silent BCBSKS submission failure     | Corrected date and dropdown event handling addresses observed client-side failure mechanisms. Rejected writes are surfaced for review. The extension never submits, and server acceptance of an enrollment still requires human validation.                                                                |

The live [BCBSKS form](https://provider.bcbsks.com/bcbsks-provider/facelets/allUsers/form/NetworkEnrollmentForm.faces) exposed 856 taxonomy options. On a blank form, bulk filling a synthetic formatted date displayed the value initially but cleared it on blur; typing the same date retained it. The page's [PrimeFaces 10 datepicker source](https://provider.bcbsks.com/bcbsks-provider/javax.faces.resource/datepicker/datepicker.js.faces?ln=primefaces&v=10.0.0) gates input parsing on a preceding keydown and restores its internal value on blur. The research form was reset and closed; no enrollment was submitted.
