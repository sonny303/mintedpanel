Gate audit

Every gate in the system — and whether it can jam

A chokehold = work queuing behind one person or one approval. Verdict per gate: is it a real gate, who can pass it, and what happens if it's ignored.

MomentVerdictWho can passIf delayed / ignored
Generation confirmTHE ONE GATEAny admin — Sowmya or Zeb, interchangeablyCandidates sit visibly in the buffer with a count — never lost, never auto-created. Deliberate by design: onboarding records reality; only a human creates work.
Payer missing from catalograre gatePlatform request (either can file)The one true external dependency; everything else about the org proceeds. Worth watching, not worth designing around today.
SOP not authored yetnever blocks—Generation proceeds on the generic checklist, visibly flagged; ops finishes Journey A whenever, future cases pick it up.
Form not captured/trainednever blocks—Cases are worked manually; the funnel shows the gap until ops closes it.
Form drift after launchnever blocksAnyone repairs, in the SOP editorFill degrades to manual for affected fields; badge persists until repaired.

Payer attachno approvalAny adminData-driven (operating states); instant; org layer implicit.
Migration enrollmentsno approvalWhoever onboards the providerA plain enrollment fact (payer, state, effective date) — never an auto-case. Expiring the fact makes the combo a candidate again.
Status changesevidence, not approvalAny writer; admin can correct backwardNo sign-off chains anywhere; the audit log is the accountability, not a pre-approval.
Reapply after denialone clickAny writerSame case, new cycle; no one authorizes it.
Exclusion / restorereasoned, reversibleAny adminNever deletes; the board keeps it accounted for.
The verdict

One deliberate gate (generation confirm) that both actors can operate; one rare external dependency (a payer absent from the catalog); everything else warns and flows. No handoff in the system is person-to-person — every one deposits work into a visible, counted state (the buffer, the queue, the board) that whoever's available picks up. The two of you can work fully in parallel, swap hats mid-day, and nothing queues behind either of you.
